# Instagram Downloader Telegram Bot

A Telegram bot that downloads Instagram posts, reels, and carousels.

## Setup

1. Install dependencies:
   ```
   pip install -r requirements.txt
   ```

2. Get a bot token from [@BotFather](https://t.me/BotFather) on Telegram

3. Set the environment variable:
   - Windows: `set TG_BOT_TOKEN=your_token_here`
   - Linux/Mac: `export TG_BOT_TOKEN=your_token_here`

4. Run:
   ```
   python main.py
   ```

## Usage

Send any Instagram post/reel URL to the bot and it will reply with the media files.
